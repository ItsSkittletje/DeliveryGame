## Non-negotiables (summary — the master prompt wins on any conflict)

- Work milestone by milestone (§15). Never start the next milestone without the director's explicit confirmation.
- Server-authoritative design for everything that matters (doors, paranormal events, entity AI, objectives). Build every system so it can replicate later.
- Houses are data-driven (Data Assets). Adding a house must not require core-code changes.
- Interactions go through an interface/component, never hardcoded into the player character.
- Original IP only. No copied designs, floor plans, characters, UI, audio or code from The Conjuring, Phasmophobia or any other work. Unlicensed or unclear-license assets are not used. Log every third-party asset/plugin in `Documentation/AssetLicenses.md` / `ThirdPartySoftware.md` and every original creative element in `OriginalityRegister.md`.
- Never claim a build succeeded without running it. Report errors verbatim.
- Inspect files before modifying them. Commit before significant changes.
- Explain any manual Unreal Editor steps explicitly.
